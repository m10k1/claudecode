# スペースインベーダーゲーム

Webブラウザで動作するクラシックなスペースインベーダーゲームです。

## 特徴

- HTML5 Canvasを使用した滑らかなアニメーション
- レトロな雰囲気のデザイン
- スコアとライフのシステム
- レベルアップによる難易度上昇
- レスポンシブデザイン

## 遊び方

1. `index.html` をWebブラウザで開きます
2. 「ゲーム開始」ボタンをクリックします
3. 操作方法:
   - **← →（左右矢印キー）**: プレイヤーの移動
   - **スペースキー**: 弾を発射

## ゲームルール

- インベーダー（敵）を全て倒すと次のレベルに進みます
- インベーダーが地球に到達するとゲームオーバー
- ライフが0になるとゲームオーバー
- インベーダーを倒すとスコアが増加します

## 技術スタック

- HTML5
- CSS3
- JavaScript (Vanilla)
- Canvas API
